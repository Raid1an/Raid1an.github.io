Hexo博客搭建指南
技术 2026/8/13

前言

本文记录了基于 Hexo + GitHub Pages 搭建个人博客的完整过程，包括环境配置、主题安装、部署上线等步骤。

环境准备

工具 版本 说明
Node.js v20.18.0 JavaScript 运行环境
Git v2.55.0 版本控制工具
Hexo 7.3.0 博客框架

搭建步骤

1. 安装 Hexo

npm install -g hexo-cli
hexo init my-blog
cd my-blog
npm install

2. 本地预览

hexo server

浏览器打开 http://localhost:4000 即可预览。

3. 主题安装

本文使用的是 ParticleX 主题：

git clone https://github.com/theme-particlex/hexo-theme-particlex.git themes/particlex

然后在 _config.yml 中设置 theme: particlex。

4. 部署到 GitHub Pages

hexo clean && hexo generate && hexo deploy

日常写文章

hexo new "文章标题"

文章头部可以设置分类和标签：

categories:
  - 技术
tags:
  - Hexo
  - 博客

总结

Hexo + GitHub Pages 是一个免费、轻量的博客方案，配合 ParticleX 主题可以快速搭建出美观的个人博客。
